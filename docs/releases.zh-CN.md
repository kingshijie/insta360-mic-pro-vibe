# Vibe Mic Pro 中文下载说明

[返回中文使用指南](../README.zh-CN.md) · [查看英文发布页](https://github.com/kingshijie/insta360-mic-pro-vibe/releases/latest)

**把 Insta360 Mic Pro 的电源键变成豆包听写键。短按一次开始，再按一次结束，说话时不用长按键盘。**

v1.1.0 起，App 默认显示英文，可在「Settings → Language」切换到简体中文。结束听写并等文字出现后，可在 20 秒内双击电源键发送 Return。此选项默认开启，可在设置中关闭。实际双击也会切换麦克风降噪。

1. 在发布页的附件区下载 **`MicPro-Doubao-macOS-universal.zip`**。解压后将 App 拖入「应用程序」。安装包包含 Apple 芯片和 Intel 两种架构，要求 macOS 13 或更新版本。
2. 安装豆包输入法和 BlackHole 2ch，在系统蓝牙设置中配对 Mic Pro，并为 App 开启辅助功能权限。
3. 将豆包的「免按模式」设为右 ⌥，「麦克风选择」设为「自动检测」。
4. 此版本未经过 Apple 公证。如果首次打开时被拦截，可在「系统设置 → 隐私与安全性」中针对该 App 选择「仍要打开」。
